# ระบบจัดทำโครงการสอน

เว็บแอป Flask สำหรับหน้าจัดเตรียมเอกสารและข้อมูลรายวิชา ตามภาพอ้างอิง

## เริ่มต้นใช้งาน

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

จากนั้นเปิด `http://127.0.0.1:5000`

## แอป Streamlit พร้อม Gemini

รัน `streamlit run app.py` หรือ `streamlit run streamlit_app.py`
บน Streamlit Community Cloud ใช้ repository นี้ branch `main` และ entrypoint `app.py`

1. กรอก Gemini API Key จาก Google AI Studio (เก็บเฉพาะเซสชัน ไม่บันทึกลง repository)
2. อัปโหลด template DOCX ไม่เกิน 15 MB และแผนการสอน PDF ไม่เกิน 50 MB / 1,000 หน้า
3. กำหนดจำนวนสัปดาห์และข้อมูลรายวิชา ช่องว่างจะอ่านจาก PDF; ชั่วโมงเป็น 0 หมายถึงอ่านจาก PDF
4. กด **วิเคราะห์แผนการสอน** เพื่อส่ง PDF และข้อความ template ให้ Google Gemini
5. ตรวจแก้ข้อมูลรายวิชาและตาราง จากนั้นกด **ดาวน์โหลดโครงการสอน Word**

ระบบใช้โมเดลเริ่มต้น `gemini-3.5-flash` โดยไม่แสดงการตั้งค่าโมเดลในหน้า UI
การแก้ตารางและดาวน์โหลดไม่เรียก Gemini ซ้ำ การเปลี่ยนไฟล์หรือข้อมูลต้นทางจะซ่อนผลเก่าจนกดวิเคราะห์ใหม่
แอปพยายามลบ PDF ชั่วคราวจาก Gemini Files API หลังจบคำขอทั้งกรณีสำเร็จและล้มเหลว

### รูปแบบ template ที่รองรับ

รองรับช่องข้อมูล `{{ curriculum }}`, `{{ code }}`, `{{ subject }}`, `{{ level }}`, `{{ year_level }}`, `{{ h }}`, `{{ n }}`, `{{ term }}`
ตารางต้องมีแถวคำสั่ง `{%tr for r in weeks %}` หนึ่งแถว ตามด้วยแถวข้อมูลหนึ่งแถว
ที่มี `{{ r.w }}`, `{{ r.t }}`, `{{ r.p }}`, `{{ r.a }}`, `{{ r.m }}`, `{{ r.e }}`
และปิดด้วยแถว `{%tr endfor %}` โดยวางแถวเหล่านี้ติดกัน
ชื่อช่องตรงกับ template โครงการสอนที่ผู้ใช้ส่งมา และรองรับช่องที่ Word แบ่งข้อความเป็นหลาย run

ระบบเติมเฉพาะช่องที่รองรับ ไม่มีการประมวลผล Python/Jinja จากไฟล์อัปโหลด
คง styles, รูปภาพ และ custom XML ของ DOCX
แถวว่างติดท้าย loop ถูกแทนด้วยแถวที่สร้าง
เมื่อหัวตารางมีช่องแผ่นที่/หน้าที่ ระบบย้ายส่วนหัวแบบฟอร์มไปเป็นหัวกระดาษจริง
และใช้ฟิลด์ PAGE ให้ Word เรียงทั้งสองช่องอัตโนมัติ พร้อมตั้งให้อัปเดตฟิลด์เมื่อเปิดไฟล์
ไม่ใช้ PAGE ในแถวหัวตารางซ้ำ เพราะ Word อาจแสดงเลขเดิมทุกหน้า
การย้ายหัวแบบฟอร์มรองรับ template ที่มีหนึ่ง section และรักษาความสัมพันธ์ของรูปภาพไว้
ตรวจการแบ่งหน้าใน Word ก่อนใช้เอกสารจริง

### ทดสอบ

ติดตั้ง requirements แล้วรัน `python -m unittest discover -s tests -v`
การทดสอบใช้คำตอบ Gemini จำลอง ไม่ใช้ API Key และไม่ส่งเอกสารออกภายนอก
การทดสอบ upload UI ต้องใช้ Streamlit รุ่นที่รองรับ FileUploader ใน AppTest

หน้า Flask (`python app.py`) ยังคงเป็นหน้าต้นแบบเดิม ฟังก์ชัน Gemini ใช้งานผ่าน Streamlit
